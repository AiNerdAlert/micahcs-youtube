Physical Exercises

Context Window Table Exercise

Concept: Visual demonstration of context window limits and summarization

Setup:

  • Table length = context window (e.g., 200,000 tokens)
  • Kids write on pieces of paper
  • Each new piece gets pushed forward on the table
  • Papers stack up and eventually fall off the end

    • Teaching moment:

  • Shows how context fills up
  • Demonstrates why messages "fall off"
  • Introduces summarization: compress all papers into one smaller summary paper
  • Clears context window to continue

    • Grade level: 5-8

    Humans vs AI Comparison Exercise

    Concept: What are humans good at? What is AI good at?

    Topics to cover:

  • AI strengths: Speed (reading, typing, processing), pattern recognition, data analysis, consistency
  • AI weaknesses: True creativity, emotional intelligence, common sense, physical interaction
  • Human strengths: Creativity, empathy, adaptability, learning from few examples, ethical reasoning
  • Human weaknesses: Slow processing, inconsistent, gets tired, limited memory

    • Speed demonstration:

  • How fast can AI "read" vs human? (magnitudes faster)
  • How fast can AI type vs human?
  • Real-time comparison?

    • Superhumans to discuss:

  • Speed readers (Kim Peek, savants)
  • Chess/Go grandmasters
  • Mental calculators
  • What amazing things can humans do that we thought only AI could?

    • Future discussion:

  • Human augmentation (Neuralink)
  • Will humans need to augment to keep up?
  • Is that desirable? Ethical?
