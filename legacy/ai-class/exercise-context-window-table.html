Exercise: Context Window Table

Concept

Physically demonstrate how context windows work, how they fill up, and how summarization clears space.

Age Group

Grades 5-8 (10-13 years old)

Duration

~15-20 minutes

Learning Objectives

  • Understand what a context window is
  • Visualize how it fills up with information
  • See why older messages "fall off"
  • Learn how summarization frees up space

    • Materials Needed

  • Long table (represents the context window)
  • Blank paper (lots of sheets)
  • Markers or pens
  • One smaller "summary" paper (different color?)

    • Setup

    1. Table length = context window size (metaphorically ~200k tokens) 2. Starting position at one end of table 3. Students seated around table

    Activity Steps

    Part 1: Filling the Context

    1. Student writes something on a piece of paper (a message/prompt) 2. They push it forward on the table 3. Next student writes on a new paper, pushes both forward 4. Continue: each new paper pushes the stack forward 5. Eventually papers start falling off the far end!

    Teaching moment: "This is what happens when your chat gets too long! The AI can't remember the old stuff because it fell out of the context window."

    Part 2: Summarization

    1. Gather all the papers on the table 2. Read them together 3. Write a SHORT summary on the smaller paper 4. Replace all the papers with just the summary 5. Now there's room to keep writing!

    Teaching moment: "This is what AI does when it 'compacts' or 'summarizes' your conversation. It squishes the old stuff into a smaller piece so you can keep chatting!"

    Discussion Questions

  • What happened when we ran out of room?
  • Why might it be important to summarize?
  • What gets lost when we summarize?
  • How is this different from human memory?

    • Variations

  • Hard mode: Make the table shorter (smaller context window)
  • Easy mode: Allow overlapping papers (more capacity)
  • Challenge: Try to write a summary that captures EVERYTHING

    • Follow-up Digital Content

  • Show actual context window sizes of different models (GPT-4: 128k, Claude: 200k, etc.)
  • Demonstrate Clawdbot's auto-compaction in action
  • Explain token counting (rough estimate: 1 token ≈ 4 characters)
