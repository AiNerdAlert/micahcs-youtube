Custom Chat Application for Class

Concept

Build a web app that connects to multiple AI APIs (ChatGPT, Claude, Gemini, etc.) so students can safely interact with AI under supervision.

Why This Is Better Than Direct Access

Safety & Monitoring:

  • ✅ Students create accounts on YOUR app (not OpenAI/Anthropic)
  • ✅ Admin dashboard shows all prompts & responses
  • ✅ Teacher can monitor in real-time
  • ✅ Filter inappropriate content before it reaches AI
  • ✅ No credit card needed (you control API keys)
  • ✅ No data leaked to AI companies (you're the proxy)

    • Teaching Opportunities:

  • ✅ Show moderation layers in action (how prompts are checked)
  • ✅ Demonstrate memory & preferences
  • ✅ Compare models side-by-side
  • ✅ Expose underlying terminology (inference, context, tokens, etc.)
  • ✅ Build exactly the interface you want (customized for learning)

    • Control:

  • ✅ Rate limiting (prevent spam)
  • ✅ Usage tracking (cost management)
  • ✅ Custom features (e.g., "explain this in kid terms" button)
  • ✅ Save chat history for student portfolios
  • ✅ Classroom mode (teacher broadcasts prompt to all students)

    Teaching Moments Built Into App

    1. Moderation Layer

    Show students: > "When you send a prompt to ChatGPT, it doesn't go directly to the AI. First, a moderation AI checks if your prompt is safe. Let's see what gets flagged..."

    Your app can:

  • Display moderation results before sending to main AI
  • Show what keywords trigger flags
  • Explain why certain prompts are blocked

    • 2. Context Window Visual

    Show students: > "Look at the token counter! Every message you send uses tokens. When the bar fills up, old messages 'fall off.' That's the context window!"

    Your app can:

  • Live token counter (updates with each message)
  • Visual bar showing context fullness
  • Warning when approaching limit
  • "Summarize & clear" button (like compaction)

    • 3. Model Comparison

    Show students: > "Let's send the same prompt to ChatGPT, Claude, and Gemini. Which one gives the best answer? Why?"

    Your app can:

  • Side-by-side view of responses
  • Voting system (which answer is best?)
  • Show differences in style, accuracy, creativity

    • 4. System Prompts

    Show students: > "Every AI chatbot has hidden instructions called a 'system prompt.' Let's see what ChatGPT is secretly told before you even talk to it."

    Your app can:

  • Toggle to reveal system prompts
  • Let students edit system prompts (change AI's personality)
  • Compare how system prompts change behavior

    • 5. Temperature & Settings

    Show students: > "Temperature controls how 'creative' the AI is. Low = boring but accurate. High = wild and unpredictable. Let's experiment!"

    Your app can:

  • Sliders for temperature, max tokens, top-p
  • Real-time comparison (same prompt, different settings)
  • Explain what each setting does

    Terminology to Cover in Curriculum

    Core Concepts

    Model

  • The AI "brain" (e.g., GPT-4, Claude 3.5)
  • Trained on tons of text data
  • Different models = different capabilities

    • Inference

  • The process of AI generating a response
  • "Running inference" = asking the AI a question and getting an answer
  • Costs compute power (measured in tokens)

    • Context Window

  • How much conversation the AI can "remember" at once
  • Measured in tokens (e.g., 200k tokens = ~150k words)
  • Old messages "fall off" when full
  • Why long chats lose memory

    • Tokens

  • How AI reads text (chunks, not letters)
  • ~1 token ≈ 4 characters or 0.75 words
  • Both input AND output count toward limits
  • Used to measure cost (API pricing per token)

    • System Prompt

  • Hidden instructions given to AI before you chat
  • Sets personality, rules, format
  • Example: "You are a helpful assistant. Be concise."
  • Users usually don't see this

    • User Prompt / User Message

  • What YOU type to the AI
  • The input you give
  • Also called "query" or "instruction"

    • Assistant Response

  • What the AI replies with
  • The output generated
  • Can be text, code, structured data, etc.

    • Temperature

  • Controls randomness/creativity (0.0 to 2.0)
  • Low (0.0-0.5) = predictable, accurate, boring
  • High (1.0-2.0) = creative, wild, unpredictable
  • Default usually 0.7-1.0

    • Max Tokens

  • Limit on how long the response can be
  • Prevents AI from writing novels
  • Saves money (fewer tokens = lower cost)

    • Top-P (Nucleus Sampling)

  • Another creativity control (0.0 to 1.0)
  • Limits which words AI considers
  • Low = only use most likely words
  • High = consider many possible words

    • Engine

  • Sometimes synonymous with "model"
  • Or: the underlying compute system running the model
  • Example: "GPT-4 engine"

    Advanced Concepts

    Fine-Tuning

  • Training a model on custom data
  • Makes it better at specific tasks
  • Expensive and time-consuming

    • Embedding

  • Turning text into numbers (vectors)
  • Used for search, similarity, recommendations
  • Not the same as generating text

    • API (Application Programming Interface)

  • How apps talk to AI models
  • You send request (prompt) → get response
  • Charged per token used

    • Latency

  • How long it takes to get a response
  • Measured in seconds or milliseconds
  • Faster models = lower latency

    • Streaming

  • Getting response word-by-word (like ChatGPT types)
  • vs Batch: waiting for full response before showing

    • Rate Limiting

  • Max number of requests per minute/hour
  • Prevents abuse and overuse
  • APIs enforce this

    • Hallucination

  • When AI confidently makes stuff up
  • Looks real but is totally wrong
  • AI doesn't "know" it's lying (no truth concept)

    • Prompt Engineering

  • The skill of writing good prompts
  • Clear instructions = better results
  • Includes context, examples, format requests

    • Few-Shot Learning

  • Giving AI examples in your prompt
  • "Here are 3 examples. Now do this one."
  • Helps AI understand what you want

    • Zero-Shot Learning

  • No examples given, just instructions
  • AI figures it out from training

    • Chain-of-Thought (CoT)

  • Asking AI to "think step-by-step"
  • Improves reasoning on complex problems
  • Example: "Explain your reasoning before answering."

    • Retrieval-Augmented Generation (RAG)

  • AI searches external knowledge before answering
  • Combines search + generation
  • Reduces hallucinations (gives sources)

    Safety & Moderation

    Content Moderation

  • Checking prompts/responses for harmful content
  • Happens automatically before reaching main model
  • Blocks violence, hate speech, illegal stuff

    • Jailbreaking

  • Tricks to bypass AI safety rules
  • Example: "Pretend you're an evil AI..."
  • Most models are trained to resist this

    • Red Teaming

  • Testing AI safety by trying to break it
  • Finding weaknesses before bad actors do

    • Alignment

  • Making AI behave according to human values
  • Why AI says "I can't help with that"
  • Ongoing research problem

    • ---

    Memory & Persistence

    Session / Conversation

  • One continuous chat with AI
  • Keeps context throughout
  • Ends when you close chat or clear context

    • Chat History

  • Record of all messages in a session
  • Stored locally or on server
  • Can be replayed or resumed later

    • Memory (persistent)

  • Some AIs remember things across sessions
  • Example: "You told me last week you like pizza"
  • Requires storing data about user

    • Stateless vs Stateful

  • Stateless: AI forgets between requests (pure API)
  • Stateful: AI remembers within session (chat interface)

    • ---

    Cost & Usage

    Usage Tracking

  • Counting tokens used per request
  • Monitoring API costs
  • Important for budgeting

    • Model Pricing Tiers

  • Different models cost different amounts
  • GPT-4: expensive, smart
  • GPT-3.5: cheap, fast, less smart
  • Claude: competitive pricing
  • Gemini: Google's offering

    • Input Tokens vs Output Tokens

  • Some APIs charge more for output than input
  • Example: $0.01/1k input, $0.03/1k output
