🛠️ AI Development Skills

Claude Code skills students will use during the software development process

What Are Skills?

Skills are like "power-ups" for AI coding assistants. They teach the AI specialized knowledge about specific tasks - like brainstorming, design, or debugging. Instead of explaining everything from scratch each time, skills give the AI instant expertise.

📦 Part of ShipKit

These skills align with our ShipKit development framework - a structured approach to building software. Each skill maps to a specific phase in the development process: Planning → Design → Build → Test → Deploy.

📚 Skill Libraries — Collections of related skills

⚡ Obra Superpowers

A complete software development workflow built on composable skills. Created by Jesse Vincent (obra), this library doesn't just give you individual skills - it gives you an entire methodology for building software with AI. The skills trigger automatically based on what you're doing.

How It Works

  • Starts with questions, not code
  • Creates design spec from conversation
  • Builds implementation plan
  • Uses subagents for each task
  • Enforces test-driven development
  • Reviews work automatically

Skills Included

  • brainstorming - Plan before coding
  • writing-plans - Implementation plans
  • test-driven-development - RED-GREEN-REFACTOR
  • systematic-debugging - 4-phase debugging
  • using-git-worktrees - Parallel branches
  • subagent-driven-development - Task delegation
  • requesting-code-review - Quality checks
  • writing-skills - Create new skills
📁 GitHub Repository 🔗 Skills.sh Page 📖 Blog Post (Philosophy)

Installation (Claude Code)

# Step 1: Add the marketplace /plugin marketplace add obra/superpowers-marketplace # Step 2: Install the plugin /plugin install superpowers@superpowers-marketplace # Step 3: Verify (start new session, ask to plan something) "help me plan this feature"

📍 Why We Use This

This is our primary skill library for the class. It teaches students the right way to work with AI: plan first, test your work, review before moving on. Individual skills below (like Brainstorming) come from this library.

📋 Planning Phase — Before writing any code

🧠 Brainstorming (from Obra Superpowers)

A structured brainstorming skill that helps you plan BEFORE coding. Part of the Obra Superpowers library, it asks thoughtful questions to understand your intent, requirements, and design - then creates an implementation summary you can hand off to the AI to build.

What it does

  • Asks clarifying questions
  • Explores requirements
  • Identifies edge cases
  • Creates implementation plan
  • Prevents scope creep
  • Documents decisions
📁 GitHub Repository 🔗 Skills.sh Page

Installation

# Using Claude Code marketplace /plugin marketplace add obra/superpowers /plugin install brainstorming@superpowers

📍 When Students Will Use This

Day 2-3: Before starting their app project. Students will use this skill to brainstorm their app idea, define features, and create a plan before writing any code.

🎨 Design Phase — Making it look professional

✨ UI/UX Pro Max

An AI-powered design intelligence skill that automatically generates complete design systems. Tell it what you're building, and it recommends styles, colors, fonts, and layout patterns based on your industry and goals.

What it includes

  • 67 UI styles (Glassmorphism, Minimalist, etc.)
  • 96 color palettes by industry
  • 57 font pairings with Google Fonts
  • 100 industry-specific rules
  • Auto design system generation
  • Accessibility guidelines (WCAG)
📁 GitHub Repository 🔗 Skills.sh Page 🌐 Official Website

Installation (CLI Method)

# Install the CLI tool npm install -g uipro-cli # Initialize in your project cd your-project uipro init --ai claude

📍 When Students Will Use This

Day 3-4: After planning, when students start designing their app's look and feel. The skill will generate a complete design system (colors, fonts, style) based on what kind of app they're building.
